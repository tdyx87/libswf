# 跨平台音视频解码后端（替代原先 Windows-only 的 Media Foundation）。
# 覆盖全部 SWF 编码：MP3/Nellymoser/Speex/AAC 音频 + H.263/VP6/AVC 视频。
#
# ffmpeg **不由 conan 提供**：源码构建在本环境会失败（编译量过大），而已下载好的
# 预编译 shared 开发包放在third_party/ 下，构建时通过 -DFFMPEG_ROOT=<目录> 指定：
#   third_party/ffmpeg-n8.1-latest-win64-gpl-shared-8.1   (Windows, libavcodec 62)
# build.bat 会自动把该目录作为默认 FFMPEG_ROOT，并自动拷贝 bin/*.dll 到产物目录。
# Linux/macOS 改用系统 ffmpeg（apt install libavcodec-dev…/ brew install ffmpeg），
# 同样通过 -DFFMPEG_ROOT=<根目录> 指定，或留空让 CMake 自行find。
# 渲染/字体/图像改用 vendored 方案（见third_party/），不依赖 conan 的 cairo：
#   - cairo/1.18.0 在 conan-center 无条件依赖 glib/pcre2/libffi/libgettext->libiconv，
#     而 libiconv/1.17 配方在 conan 2.x + 新 Python 下 build() 必崩（TypeError: startswith
#     first arg must be bytes...），且 glib 在 Windows 需巨量源码构建，本环境无法构建。
#   - 移动端渲染选用 vendored nanovg（OpenGL ES，GPU），比 cairo（纯软件）更适合移动端。
#   - 字体/图像用 vendored stb_truetype / stb_image（头文件库，跨平台、零构建风险）。
# 如需 FreeType 的更完整 TrueType 支持，可后续单独 conan add freetype（已验证可解析，构建待确认）。

[generators]
